## Quick facts

- **Deliverable:** autonomous forecast model (TAT/on-time % + volume) integrated into the existing agent.
- **Target:** ≥ 90% on-time per month (month is key reference period).
- **Entities:** whole operation, lab, package, workgroup.
- **Language:** Python. **Data source:** S360 LIMS.
- **Success:** backtested mid-period forecast accuracy (MAE/MAPE, on-time % error, calibrated confidence, at-risk flagging).
